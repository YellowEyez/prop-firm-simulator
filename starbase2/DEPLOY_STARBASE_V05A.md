# Deploy Project StarBase v5A

Use the complete release folder named exactly `starbase`.

Recommended GitHub layout:

```
prop-firm-simulator/
  starbase/
    app.py
    requirements.txt
    ...
```

Streamlit Main file path:

`starbase/app.py`

Do not rename the deployed folder to a long release filename and do not add `(1)` suffixes to the deployed app folder.
