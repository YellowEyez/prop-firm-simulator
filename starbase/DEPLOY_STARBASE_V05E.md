# Deploy StarBase v5E

1. Replace the existing repository `starbase` folder with the `starbase` folder from the v5E full ZIP.
2. Do not rename the folder.
3. Streamlit Community Cloud main file path remains `starbase/app.py`.
4. After deploy, open **Prop-Firm Rule Truth (v5E)** for the Step-26 certification test.

The v5E release changes the rulebook schema from 3.0.0 to 3.1.0 and refreshes official rule semantics to 2026-08-12. It does not delete the legacy `prop_firms.json` reference file.
