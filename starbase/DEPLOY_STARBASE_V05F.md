# Deploy StarBase v5F

- Replace the existing GitHub `starbase` folder with the `starbase` folder from the full v5F ZIP.
- Keep the folder name exactly `starbase`.
- Streamlit Main file path remains `starbase/app.py`.
- Open `Golden Verification Lab (v5F)`.
- Click `Run Golden Verification Suite` once.
- Certification passes only if it shows **13 fixtures / 13 passed / 0 failed / Rulebook schema 3.1.0**.
