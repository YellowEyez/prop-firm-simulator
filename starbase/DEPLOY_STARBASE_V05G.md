1. Replace the existing GitHub `starbase` folder with the `starbase` folder from the v5G full ZIP.

3. Streamlit Community Cloud main file path remains `starbase/app.py`.

5. Run **Run Live State Verification Suite**. Certification target: **7 passed / 0 failed**.
