# Deploy StarBase v5I

1. Replace the deployed `starbase` folder with the `starbase` folder from the full v5I ZIP.
2. Do not rename the folder.
3. Streamlit Main file path remains `starbase/app.py`.
4. Open **Live Payout / Withdrawal Lab (v5I)**.
5. Click **Run Live Payout Verification Suite**.
6. Expected certification result: **10 fixtures / 10 passed / 0 failed**.
7. If 10/10 passes, Step 30 is deployment-certified and StarBase progress becomes **34 / 60 verified**.
