# Deploy Project StarBase v4A

Use the **full repository ZIP**. This release follows the same flat repository-root layout as the working v3.5.2 build.

1. Keep your working v3.5.2 GitHub version as a commit/tag/backup.
2. Replace the repository working files with the contents of the v4A full ZIP, or extract over your local GitHub Desktop clone and choose Replace.
3. Commit and push.
4. Keep the Streamlit entrypoint pointed at this release's `app.py`.
5. Open the new workspace: **Single-Account State + Ledger (v4A)**.
6. Create a LucidFlex 50K Evaluation account and confirm the page loads with a $50,000 prop balance and a reference $48,000 initial floor.

v4A is accounting-only. Do not interpret its reference floor as an enforced drawdown yet; that begins in v4B.
